# Contenido

## Shows — [`shows.txt`](shows.txt)

1. Lápiz ✏️.
2. Una línea por show: `15/11 | El Portal | https://link-de-entradas` (el link es opcional).
3. **Commit changes**.

Se ordenan por fecha. Los que pasaron se ocultan solos.

## Footer — [`footer.txt`](footer.txt)

1. Lápiz ✏️.
2. Cambiá `link:` y `texto:`.
3. **Commit changes**.

## Fotos — [`galeria`](galeria)

1. **Add file** → **Upload files**.
2. Arrastrá las fotos (.jpg o .png, no HEIC).
3. **Commit changes**.

Para borrar una: abrila → **···** → **Delete file** → **Commit changes**.

Descripciones y flyers (opcional): [`galeria/descripciones.txt`](galeria/descripciones.txt).
